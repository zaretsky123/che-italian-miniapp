# che-italian-miniapp

Демо Telegram Mini App для бистро «Чё, Итальянец?» на Варшавской.

Меню, корзина, тестовое оформление заказа на самовывоз и экран сотрудника. Реальные заказы, оплата и Telegram-уведомления не подключены. Данные находятся в памяти вкладки и сбрасываются при обновлении. Для теста используйте вымышленные контакты.

## Источники

Единственный источник названий, цен и данных заведения: https://che-italian.ru/varshavskaya/ (проверено 2 октября 2026 года). Не смешивать с меню Скандинавии или другим блоком главной страницы. Фото бумажного меню используется только как визуальный референс изображений, не как источник цен, размеров и состава. Опубликованные цены перед реальным запуском необходимо подтвердить у владельца.

## Публикация

Settings → Pages → Deploy from a branch → main → / (root) → Save.

Адрес: https://zaretsky123.github.io/che-italian-miniapp/

В BotFather через /setmenubutton укажите опубликованный URL и текст «Меню 🍕».

## Разработка

Статические файлы: index.html, style.css, app.js. Сборка не требуется. Не добавляйте токен бота или другие секреты в этот публичный репозиторий.

Проект — неофициальное демонстрационное предложение. Время приёма заказов в форме пока демонстрационное и не является подтверждённым графиком кухни.
